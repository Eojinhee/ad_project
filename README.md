# 🏭 화학 공정 이상 탐지 시스템 (Chemical Process Anomaly Detection)

> **"화학 공장 센서 데이터를 행 단위 판정에서 'Run 단위 집계'로 재정의하고, 통계 기반 PCA(1주 차)와 이동통계 융합 LightGBM(2주 차) 실험을 통해 리더보드 1위(F1 0.9520)를 달성한 엔지니어링 과정"**

- **대회 기간**: 2026.06.24 ~ 07.14 (개인 프로젝트)
- **평가 지표**: F1-Score (이상 = 1, 정상 = 0)
- **핵심 과제**: 
  - 센서 측정값(`xmeas_1~41`)과 제어 조절값(`xmv_1~11`) 등 총 52개 변수를 바탕으로 공정의 정상/고장 여부를 판정.
  - 학습 데이터(`train`)에 정상 데이터만 존재하므로 단순 분류가 아닌 **비지도 이상탐지(Unsupervised Novelty Detection)** 문제로 접근.

---

## 📌 1. 문제의 본질 재정의 (구조적 핵심)

- **데이터 구조 분석**: "한 번의 가동(Simulation Run) 단위 전체가 정상이거나, 전체가 고장"이라는 라벨 규칙을 발견함. (Train 500개 Run, Test 740개 Run)
- **공식 Baseline의 한계**: 71만 개의 행(Row)을 개별 판정하여 F1 0.5607에 머무름.
- **접근 방식 전환**: 행 단위 예측이 아닌, **"740개 Run 단위 전체를 모아서 판단하는 집계 문제"**로 재정의하여 성능을 극적으로 끌어올림 (+69% 향상).

---

## 🔬 2. 외부 데이터 도입 및 검증 (TEP 벤치마크)

- **배경**: 학습 데이터에 고장 사례가 없어 공개 벤치마크인 TEP(Tennessee Eastman Process) 외부 데이터를 도입함.
- **데이터 유출 검증**:
  - 우리 `train` 데이터 vs 외부 정상 `train` ➡ **100% 일치 (동일 데이터 검증)**
  - 우리 `test` 데이터 vs 외부 TEP 테스트 데이터 ➡ **일치 행 수 0건 (정답 유출 0% 확인)**
- **결론**: 대회 규정상 허용된 외부 데이터에서 오직 "고장 패턴(Fault 1~20번)"만을 학습 자산으로 확보함.

---

## 🛠️ 3. [1주 차] 통계 기반 PCA 모델링 및 22회 실험

정상 데이터의 통계적 패턴을 학습하기 위해 PCA를 도입하고, 모든 하이퍼파라미터를 후보군 비교 실험으로 확정함.

- **주요 실험 및 최적화 결과**:
  - **설명분산 비율 (`90%` 선택)**: 노이즈 배제와 정보 보존의 균형점인 31개 주성분 선택.
  - **분석 윈도우 (`161~960 partial`)**: Test 런의 앞 160개 샘플은 항상 fault 주입 전 정상 구간이라는 도메인 지식을 반영해 후반부에 집중.
  - **집계 방식 (`top20pct` 선택)**: 960개 이상 점수 중 노이즈에 취약한 평균(`mean`)이나 극단적인 최댓값(`max`) 대신, 강한 신호에 집중하는 상위 20% 평균 채택.
  - **Threshold 설정 (`p99 = 0.280`)**: 불균형한 외부 검증 대신 100% 확실한 train 정상 데이터의 99분위수를 수학적 임계값으로 설정. Test 점수 히스토그램의 자연스러운 경계선(Gap)으로 교차 검증 완료.

---

## 🚀 4. [2주 차] 외부 데이터 지도학습(LightGBM) 고도화

정상만 보던 PCA를 넘어, 외부 고장 데이터(480개 Run × 20개 Fault)를 직접 학습시키는 지도학습 파이프라인으로 확장함.

- **EDA 및 피처 엔지니어링**:
  - **이동통계량 추가 (핵심 성공 요인)**: 화학 공정 고장은 서서히 진행되므로, 지난 10분간의 추세를 나타내는 이동평균/표준편차(`Window=10`, 변수 10개)를 피처에 결합함.
- **모델 파라미터 최적화**:
  - `n_estimators=200`, `learning_rate=0.05`, `threshold=0.3` 조합으로 홀드아웃 **F1 1.0000** 달성.
